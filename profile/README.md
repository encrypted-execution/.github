# Encrypted Execution

**A secure architecture that prevents any and all unauthorized code from executing. Ever.**

🌐 **Website & whitepaper: [encrypted-execution.com](https://encrypted-execution.com)**

## Projects

- **[encrypted-linux](https://github.com/encrypted-execution/encrypted-linux)**: a Linux distribution built with a scrambling GCC, so programs built outside the build's closure cannot execute on the target.
- **[evasive-linux](https://github.com/encrypted-execution/evasive-linux)**: continuous in-kernel re-randomization using livepatch as a moving-target defense.
- **[php](https://github.com/encrypted-execution/php)** and **[wordpress](https://github.com/encrypted-execution/wordpress)**: Docker Official Image packaging for PHP and WordPress with Encrypted Execution.
